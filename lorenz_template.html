What the graph shows At first, the path looks like a butterfly circling around two wings. It is not a butterfly moving through space: each point represents three numbers describing the system at one moment, and the line shows how those numbers change over time. The same rule drives the motion throughout. A tiny change in the starting numbers can eventually make the path very different, even though it stays within the butterfly-shaped region. The motion is not random, but it can be hard to predict far ahead.

Analysis connections

The question I’m trying to answer: How can a simple deterministic rule produce a path that keeps moving, stays bounded, and switches between two wings?

What I expect: A fixed starting state should determine one trajectory, but nearby starts may separate. I also want to know whether a tiny blob of starting states expands or contracts overall.

How I connect this to analysis I picture a cloud of nearby starting points. The equations can stretch it in some directions and squeeze it in others. The Jacobian checks those local changes; divergence summarizes whether the cloud expands or shrinks overall. Here, net squeezing happens alongside local stretching. The curve integral adds up the field along the path, but these are model coordinates, so it is not physical work or energy.

1. Follow the state

I read the system as a velocity vector at every point in phase space. The curve follows that vector, so its coordinate differentials are the equations multiplied by time’s differential.

2. Try a curve integral

I turn the vector field into a one-form and integrate it along its own trajectory. Since the trajectory’s tangent is the field itself, the integrand becomes the squared speed in these coordinates.

This is a numerical value for this run, not physical work or energy: the coordinates are model states, and the value depends on their scaling.

3. Check volume with divergence

If the flow is contracting in phase space, I expect a small 3D blob around a state to shrink. The constant divergence gives that rate.

A tiny volume shrinks by about a millionth per unit of time. This is volume contraction, not a claim that every pair of points gets closer.

4. Use the Jacobian locally

Divergence gives the net volume change, while the Jacobian shows how nearby differences stretch or contract in each direction. Those local directions change as the orbit moves, so one linear approximation cannot describe the whole butterfly.
